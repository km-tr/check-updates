### [Release v7.0.1: brainstorming retune, skills that better survive compaction, contribution templates (#2581)](https://github.com/obra/superpowers/commit/2ce8aa15d05bd57213e6f746f953aafb7ded7a8b)

**コミット:** `2ce8aa1` | **日時:** 2026-10-21 17:00 UTC-4 | **作者:** Jesse Vincent

v7.0.1のリリースコミット。多数の改善・修正をバンドルしたスクワッシュマージ。主な変更点：

#### brainstorming スキル
- **3パスルーター精度改善**: spike / bounded / architectural の分類を明示的に宣言、一方向ラチェットと承認ゲートを全経路に追加。
- **bounded の定義厳格化**: 「このリポジトリ内の既存コード」に限定。ジャンルの馴染みやすさではなく実コードの有無で判定するよう修正（Claude Code が空リポジトリを bounded と誤分類する問題を修正）。
- **bounded 承認ゲートをハードストップに**: 実装前に承認を強制、未承認のまま進む挙動を修正。

#### SDD (Subagent Driven Development) スキル
- **ライフサイクル再設計**: resume-based fix loop・5ラウンドブレーカー・合理化テーブルを導入。`SKILL.md` を大幅圧縮し、詳細を `references/` 配下のファイルに分割：
  - `batching.md` — 同形小タスクのバッチ化ルール
  - `fix-loop.md` — 修正ループの制御フロー
  - `preflight.md` — ペアワイズチェック・台帳テーブル出力
  - `final-review.md`, `handling-reports.md`, `resuming.md`, `cannot-verify.md`
- **実装者・レビュアーがサブエージェントを派遣禁止**: 深度2のワーカー発火レビューを排除（評価: 9/9→0/6で解消）。
- **非壊滅的コンフリクトは即断即決**: コントローラーが台帳にルーリングを記録して作業継続。破壊的操作・セキュリティ操作のみ継続ハードストップ。
- **プリフライトがペアワイズチェックを台帳として出力**: ファイル/インターフェースを共有するタスクペアとタスク内自己一貫性を可視化。
- **コントローラーは長い待機か無待機**: 大量の短いポーリングをイベント駆動型の長待機に置換。

#### writing-skills スキル
- `SKILL.md` を圧縮し詳細を `references/` に分割:
  - `bulletproofing.md`, `discovery.md`, `flowcharts.md` を新規追加
  - `CLAUDE_MD_TESTING.md`, `anthropic-best-practices.md`, `graphviz-conventions.dot`, `persuasion-principles.md` を `references/` へ移動

#### Hermes プラグイン
- **起動注入を `pre_llm_call` フックに変更**: `on_session_start` の `ctx.inject_message` は呼び出しても False を返し何も届かないことが判明。初回ターン時に `pre_llm_call` から `{"context": ...}` を返す方式に修正。
- **スキル登録を `pathlib.Path` に修正**: `ctx.register_skill` に str を渡すと AttributeError でプラグイン全体が無音で無効化される問題を修正。
- **テストスイートを新メカニズムに対応**: 19テスト全パス。インストールドキュメントを README に集約。

#### systematic-debugging スキル
- **find-polluter.sh のパスプレフィックス修正**: `find .` が `./-` プレフィックス付きパスを返すため `-path "src/**/*.test.ts"` がマッチしない問題を修正（#2011）。先頭の `./` を自動除去し、`**` も適切に処理。

#### finishing スキル
- **ワークツリー削除時の未追跡ファイル対応**: `git worktree remove` が未追跡・変更ファイルで拒否した際に `--force` で強制削除する代わり、人間パートナーに確認する手順を追加（#2016の計画消失・#1223の汚染ツリー問題への対応）。

#### その他
- **docs/plans/ 14件を削除**: 完了済みプラン文書（2026-01〜2026-10）を大規模整理。
- **executing-plans スキル**: `SKILL.md` を削除（52行）。
- **using-superpowers**: dangling な `subagent-support` アンカーへのリンクを削除（#2010）。
- **codex**: multi-agent ガイダンス修正（close_agent 削除・role files の attach 方法・full-history フォーク等）、イベント駆動待機、スポーン時の明示的 model+effort 指定。
- **バージョンバンプ**: 全プラグインマニフェスト（Claude / Codex / Cursor / Antigravity / Kimi / Muse / Devin / Hermes / OpenCode / Gemini）を v7.0.1 に更新。

**fix(codex): suppress SessionStart hook auto-discovery with empty hooks object**

v6.1.0 で Codex hooks を削除したにも関わらず、Codex の `load_plugin_hooks` がデフォルトフォールバック `hooks/hooks.json`（Claude Code 向け）を自動検出して再登録していた。`.codex-plugin/plugin.json` に `hooks: {}` を明示宣言することでフォールバックを抑制。`hooks` フィールドが absent・空配列・空リストではいずれもフォールバックが発動するため `{}` の厳密な指定が必要（+18/-2行、2ファイル）。
